# 📝 Blog Project / Blog Projesi

## 🇹🇷 Türkçe

Kullanıcıların kolayca blog oluşturup paylaşabilecekleri basit bir blog web uygulaması.

Bu projede kullanıcılar **başlık**, **açıklama**, **blog türü** ve **kullanıcı adı** bilgilerini girerek yeni bir blog oluşturabilir ve oluşturdukları blogları görüntüleyebilir.

> ⚠️ Bu proje ilk sürümdür (v1). İlerleyen zamanlarda geliştirmeye devam edersem yeni özellikler eklemeyi planlıyorum.

### 🌐 Canlı Demo

**Demo:** https://blog-project-1hi1.vercel.app/blog

---

## 🚀 Özellikler

* Blog oluşturma
* Başlık ekleme
* Açıklama ekleme
* Blog kategorisi seçme
* Kullanıcı adı ile paylaşım yapma
* Oluşturulan blogları listeleme
* Basit ve kullanıcı dostu arayüz

# 🇬🇧 English

A simple blog web application where users can create and share blog posts.

In this project, users can create a new blog by entering a **title**, **description**, **blog category**, and **username**, then view the published blogs.

> ⚠️ This is the first version (v1) of the project. More features may be added in future updates.

### 🌐 Live Demo

**Demo:** https://blog-project-1hi1.vercel.app/blog

---

## 🚀 Features

* Create blog posts
* Add a title
* Add a description
* Select a blog category
* Publish posts with a username
* View all created blog posts
* Simple and user-friendly interface

---
